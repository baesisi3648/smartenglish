# 스마트해법영어 백운밸리점 — 홈페이지 + 블로그 스튜디오

| 구성 | 어디서 실행 | 설명 |
|---|---|---|
| 홈페이지 `/` | Vercel 배포 | 학원 소개, 네이버 예약·문자 상담, 블로그 최신 글(RSS, 1시간 갱신) |
| 블로그 스튜디오 `/studio` | 웹(Gemini / DeepSeek API) + 원장님 PC(ChatGPT / Claude 구독, ACP) | 사진 + 주제 → 블로그 스타일 초안 |

> 📘 **처음 쓰는 분은 [스튜디오 설명서](./스튜디오%20설명서.md)를 보세요.** (웹으로 바로 쓰기 / PC 설치 / 글 만들기 / 문제 해결)

학원 정보(주소·전화·교습비 등)는 모두 `src/content/academy.ts` 한 곳에서 관리합니다.
`verify: true` 항목은 화면에 **[확인 필요]** 배지가 붙습니다.

## 블로그 스튜디오 사용법 (원장님 PC)

### 1. 처음 한 번 — 준비
1. [Node.js LTS](https://nodejs.org) 설치 — **이것만 직접 설치**합니다.
2. `web` 폴더의 **`처음 설정.cmd`를 더블클릭** → 아래가 순서대로 자동 진행됩니다.
   - 필요한 프로그램 설치 (`npm install`, 몇 분)
   - **관리자 비밀번호**를 만들어 화면에 한 번 보여 줌 → 메모해 두세요 (저장 위치 `web/.env.local`)
   - 바탕화면에 **'블로그 스튜디오'** 아이콘 생성
   - AI 구독 로그인 (ChatGPT / Claude 중 선택, API 키 불필요)
   - AI 연결 프로그램은 첫 초안을 만들 때 자동으로 받아 옵니다.

AI 로그인을 나중에 하거나 다른 AI를 추가하려면:

| AI | 로그인 방법 | 필요한 구독 |
|---|---|---|
| ChatGPT (기본) | `npx @openai/codex login` | ChatGPT Plus / Pro |
| Claude | `npx @anthropic-ai/claude-code` 실행 → `/login` | Claude Pro / Max |

- 터미널로 하려면 `npm run studio:setup` (설치·AI 로그인 단계 없이 비밀번호와 아이콘만 만듦)
> Gemini는 지원하지 않습니다. Google이 개인 계정의 Gemini CLI 로그인을 중단했습니다(2026-11 확인).

- 비밀번호를 직접 정하려면 `npm run studio:setup -- --password 원하는비밀번호` (8자 이상, `#` `$` 따옴표 공백 불가)

### 2. 매번 — 실행
- 바탕화면 **'블로그 스튜디오'** 아이콘을 더블클릭하면 서버가 켜지고 브라우저가 열립니다. → 비밀번호 입력
- 또는 홈페이지 맨 아래 **'관리자'** 링크 → 비밀번호 → **'내 PC 스튜디오 열기'**
  (배포 사이트에서도 비밀번호를 쓰려면 Vercel 환경변수 `STUDIO_PASSWORD`에 같은 값을 넣습니다)
- 수동 실행: `npm run studio` → http://localhost:3456/studio

### 3. 글 만들기
1. AI 선택 → 글 유형 선택 → 내용 입력 (점수·인원·학생 말은 **직접 입력한 것만** 글에 들어갑니다)
   - **검색 키워드는 여러 개 선택**할 수 있습니다. ★표시된 첫 키워드가 제목 끝 `[ ]`에 들어가고, 나머지는 태그 앞쪽과 본문에 자연스럽게 들어갑니다. 직접 입력도 됩니다(최대 12개).
2. 사진 올리기 (최대 6장, 올릴 순서대로) → 개인정보 가림·보호자 동의 확인 체크
3. **초안 만들기** (1~3분) → 제목 / 본문 / 태그 각각 **복사** → 네이버 블로그 에디터에 붙여넣기
4. 본문의 `[사진N]` 자리에 해당 사진을 올리고, 내용 확인 후 **직접 발행**

> 인사말, `" 감사합니다 "`, 연락처, 주소, 고정 태그는 AI가 아니라 시스템이 `academy.ts`에서 붙입니다.

## 개발

```bash
npm run dev      # 홈페이지 개발 서버 (스튜디오 꺼짐)
npm run studio   # 스튜디오 켜진 개발 서버 (127.0.0.1:3456)
npm run build && npm run lint
```

### 스튜디오 보안 메모
- **로그인**: `/studio`와 생성 API는 관리자 비밀번호 로그인이 필요합니다. 세션은 `STUDIO_SECRET`(32자 이상 무작위, 비밀번호와 독립)으로 서명한 httpOnly 쿠키이고 12시간 유지됩니다. 비밀번호나 서명키를 바꾸면 모든 세션이 무효가 됩니다. 로그아웃은 그 브라우저의 쿠키만 지웁니다.
- **대입 방지**: 같은 IP에서 5회 틀리면 1분, 전체 합계 10분 30회 실패면 5분간 모든 로그인을 잠급니다.
- **ChatGPT·Claude(ACP)**: `npm run studio`(127.0.0.1에만 열림, `STUDIO_LOOPBACK=1`)로 띄웠을 때만, localhost 출처 요청만 받습니다. Vercel에서는 항상 꺼집니다.
  - 자식 프로세스에는 실행에 필요한 환경변수만 넘깁니다(허용 목록). 비밀번호·서명키·API 키는 전달되지 않습니다.
  - 빈 임시 폴더에서 실행하고, 도구 권한 요청은 모두 거절하며, 지원하면 읽기 전용 모드로 전환합니다. 그래도 에이전트 자체의 읽기 도구까지 완전히 막지는 못하므로, 응답에 서버 비밀값이 섞이면 가린 뒤 돌려줍니다.
  - 동시 실행은 1건, 타임아웃은 4분이고, Windows에서는 프로세스 트리째 종료합니다.
- **Gemini·DeepSeek(웹)**: 서버에 `GEMINI_API_KEY` / `DEEPSEEK_API_KEY`가 있을 때만 켜집니다.
  - 모델 변경: `GEMINI_MODEL`(기본 `gemini-flash-latest`), `DEEPSEEK_MODEL`(기본 `deepseek-flash`). `DEEPSEEK_IMAGES=0`이면 DeepSeek에 사진을 보내지 않고, 사진 입력을 거부하면 글만으로 재시도합니다.
  - 사용량: IP당 1시간 20건, 전체 1시간 60건, 출력 토큰 상한(Gemini 8192, DeepSeek 4096). 서버 메모리 기준이라 Vercel 인스턴스끼리 공유되지 않으므로 **각 AI 콘솔에서 월 지출 상한도 설정**하세요.
  - 사진은 화면에서 긴 변 1600px JPEG로 줄여 보내고(Vercel 요청 4.5MB 한도), 서버는 파일 앞부분(시그니처)으로 JPG·PNG·WEBP만 받습니다.
- **CSRF**: API는 같은 출처 Origin과 `X-Studio-Request` 헤더가 모두 있어야 받습니다(배포 사이트는 https만). 쓸 수 있는 AI가 없으면 생성 API는 404입니다.
- **오류**: 화면에는 고정 문구와 오류 번호만 보여 주고, 자세한 내용은 비밀값을 가린 뒤 서버 로그(`[studio] 오류번호`)에만 남깁니다.
